## 本次更新（3.1.3）

适配 Surge TestFlight 新增的 `GET /v1/policies?include_external=true`；旧版本 Surge 下策略组详情保持原样。

- 策略组详情识别来自外部策略组（`policy-path`）的节点，标为「外部」
- 「全部测速」现在也会测外部节点：外部节点不能按名称引用，面板按 Surge 返回的 identifier 经脚本 `$httpClient` 的 `policy` 选项逐个请求计时（需开启脚本功能），数值为完整 HTTP 耗时；失败时显示具体原因

## 上次更新（3.1.2）

- 仪表盘点按实例名改为原生下拉菜单，直接列出全部实例一键切换，末尾「管理实例…」进入实例页；点按区域加大到整行高度，首页 Tab 模式下不再与左右翻页手势抢点击
- 修复首页 Tab 模式下实例页标题「实例」大字压在第一行实例上、顶部被截断的问题：实例页改为带导航栏的 sheet，标题居中显示，右上角「完成」关闭
- 外部资源 / IP 归属：Surge 回复 `unknown path` 时明确说明是当前构建尚未提供该接口（Surge iOS TestFlight 5.102.0 (3862) 即如此，Mac 6.10 已可用），不再建议重启引擎

## 更早（3.1.1）

- 外部资源 / IP 归属不可用时不再只提示「需要 5.23+」：面板从不比较版本号（TestFlight 5.102 即 5.23 RC），只看接口是否响应。现在会显示实际请求、HTTP 状态、响应内容与正在运行的引擎版本（读取响应头或 `$environment`），并可一键重试，便于判断是否需要在 Surge 中断开重连以重启引擎，或当前实例连的是另一台设备
- IP 归属的「不可用」记录只保留 1 分钟，重启引擎后无需重开脚本即可恢复

## 更早（3.1.0）

## 更早（2.1.0）

- 实例 API Key 从普通 Storage 迁入脚本隔离的 iOS Keychain；旧版明文数据会在确认写入成功后自动移除
- 添加本机 / 局域网预设、字段校验、公网地址确认、可信网络提示与可复制参考的 Surge 侧配置
